# 555-LED-Chaser

A custom-designed 555 Timer LED Chaser PCB built using KiCad. The board uses a 555 timer to generate clock pulses and a counter IC to create a sequential LED chasing effect.

## Features

- Adjustable chase speed using potentiometer
- Two operating modes:
  - Sequential LED chaser
  - All LEDs ON
- Custom PCB designed in KiCad
- Beginner-friendly electronics project
- Through-hole components for easy assembly

## How It Works

The NE555 timer is configured in astable mode to generate periodic clock pulses.These pulses are fed into the counter IC, which activates the LEDs one after another, creating the chasing effect.The potentiometer changes the timing capacitor charging/discharging rate, allowing the user to control the chase speed.

## Modes

The mode button selects between:
- Sequential LED Chaser
- All LEDs ON

## Building it yourself

1. Download the Gerber files.
2. Manufacture the PCB.
3. Purchase components using the BOM.
4. Solder all components.
5. Apply power.
6. Adjust speed using the potentiometer.
7. Change modes using the push button.
